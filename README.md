# **Sahasam – Web-Based Adventure Game (Prototype)**

### [![Play Now](https://img.shields.io/badge/PLAY%20NOW-Click%20Here-brightgreen?style=for-the-badge)](https://godsonmd.github.io/Sahasam-Game/Front_Page.html)
A Phaser.js–powered web adventure game developed as part of an internship project at **NarrowLabs Ltd.**
The game was originally created to promote the Malayalam movie ***Sahasam***, but the campaign was shelved before release.
The current build is a **fully playable prototype**, with several planned features pending implementation.

---
## 🚀 **Overview**

**Sahasam** is a 2D adventure game inspired by classic **GBA Pokémon** titles.
Players explore a jungle-themed overworld and an underground castle floor, complete mini-games, and interact with the environment.

The world was built using **Tiled** and fantasy/medieval tileset resources.

---
## 🎮 **Gameplay Features**

### 🌍 **Overworld**

* Jungle environment with fantasy and medieval elements
* Underground castle floor
* Tile-based maps built using **Tiled**

### 🕹️ **Mini-Games (8 Total)**

The game includes **eight** fun and varied mini-games, such as:

* Tile Unscramble
* Block Jump
* Flappy Bird–style
* And more…

Each mini-game was independently designed and integrated into the adventure.

---

## ⚠️ **Prototype Status**

Some features were planned but **not yet implemented**:

* OTP authentication
* Character sprite updates
* Dialogue systems
* Payment flow

Despite this, **the overworld and all mini-games are playable**.

---

## 🛠️ **Tech Stack**

### **Frontend**

* **Phaser.js**

### **Backend (AWS)**

* **DynamoDB** – Stores player info and game state
* **AWS Lambda (Python)** – Backend logic
* **API Gateway** – REST API routing
* **EC2** – Hosting
* **SNS** – Notifications / messaging
